Project Strategic Analysis

Sheikh Mubarak’s Kiosk AR Experience [Marker-Based Tracking]

Overall Project Briefing

Core Objective

To transform a static historical monument into an immersive storytelling portal. Using Marker-Based AR, we bridge the gap between 1897 and the present day, allowing users to witness the governance, trade, and architectural legacy of Sheikh Mubarak through a 2:45-minute guided AR journey.

Duration ~2:45 Mins
Target Platforms iOS / Android
Tech Stack Unity / URP
AR Mode Marker Tracking

Development Timeline (10-Week Roadmap)

Phase Focus Duration

Phase 2: Asset Creation 3D Modeling, VFX Silhouettes, Spatial Audio 3 Weeks
Phase 3: Integration Unity Scene Flow, AR Logic, Visual Tuning 3 Weeks
Phase 4: Launch Prep Performance optimization, QA, App Store Submission 2 Weeks

Operational Risks

  • ● Marker Occlusion: Crowd movement blocking the kiosk trigger.
  • ● Lighting Shift: Harsh shadows affecting image recognition.

Strategic Solutions

  • ● Implement Slam-Extended tracking for persistence after initial lock.
  • ● Utilize high-contrast feature point detection for building facade.
