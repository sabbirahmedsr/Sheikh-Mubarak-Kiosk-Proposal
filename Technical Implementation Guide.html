Initial Setup for AI Image Generators

Copy and paste this section as your first interaction with the AI. This establishes the camera height, architectural style (aligned with 3D scans), and Unity technical constraints.

Perspective: Mobile AR (Augmented Reality) application view. Camera: Handheld smartphone height (1.5m), looking slightly upward. Real-time camera feed look with natural daylight. Subject: Sheikh Mubarak’s Kiosk, Kuwait. Historic two-story white stone structure with a wooden balcony (refer to 3D scans). Art Style: Unity URP assets: Clean 2D sprites, glowing line-renderers, and minimalist UI text. Constraint: Unity-achievable graphics. No over-complex CGI. Focus on clean silhouettes and simple particle effects.

Unity Technical Workflow

ARFoundation: ARTrackedImageManager Unity VFX Graph (Circle Particles) Standard LineRenderer Component Additive Glow Shader (URP)
  • Image Marker:Upload as a Reference Image to an AR Resource Library to trigger tracking upon detection.
  • Dust Prefab:A simple Quad with an unlit amber sprite used as a template for the VFX Graph spawn.
  • Wireframe Mesh:Extracted silhouette mesh from 3D scan used for the LineRenderer positions.
  • UI Canvas:Screen-Space Overlay with a Vertical Layout Group for consistent text anchoring.

Unity Technical Workflow

Custom Occluder Shader (Write to Z-Buffer only) Billboard Sprite Renderer (Transparent/Cutout) AR Mesh Occlusion (if using LiDAR/Meshing)
  • Proxy Occluder Mesh:Simplified 3D railing model that is invisible but blocks rendering of sprites behind it.
  • Silhouette Atlas:Collection of character poses in one texture for optimized sprite rendering.
  • Occlusion Material:URP material using a Depth-Only shader to handle spatial layering correctly.
